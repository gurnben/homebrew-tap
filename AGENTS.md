This file provides guidance to AI coding assistants when working with this repository.

## Project Overview

Homebrew tap for OpenShift Online CLI tools. Contains formulae for installing OCM CLI and related tools via Homebrew on macOS and Linux.

## Key Information

- This is a Homebrew tap repository — it contains Ruby formula files
- Formulae define how to download, build, and install OCM tools
- Updated when new releases of OCM CLI tools are published

## Conventions

- Follow Homebrew formula conventions for Ruby files
- Test formulae with `brew audit --formula` and `brew test`
